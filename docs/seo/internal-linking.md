# Internal linking

## Required relationships

- Home -> games, trending predictions, leaderboards, standings, marketplace and active affiliate offers.
- NFL hub -> schedule, scores, standings, predictions, odds, stats, injuries, teams, players and playoffs.
- Week -> each game center plus week predictions/odds.
- Game center -> both teams, week hub, week predictions, standings and each public prediction.
- Team -> its games and players; player -> official game logs and linked game centers.
- Public prediction -> game center and predictor; profile -> full prediction history, followers/following.
- Super Bowl hub -> all ten hub children; child pages link back through breadcrumbs/context.

Use descriptive text, not repeated exact-match keyword stuffing. Only link to entities that exist. Aliases redirect to the canonical route and must not appear in primary navigation or sitemaps.
