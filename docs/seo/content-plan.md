# SEO content plan

No standalone article inventory is generated in this release. The first content work should improve real product pages rather than create thin pages.

## Launch

- Validate unique titles/descriptions/H1/canonicals for all core hubs.
- Populate teams, schedule, players, standings, injuries and odds from providers.
- Ensure every game center contains real kickoff/status, score/odds provenance, community predictions and contextual links.
- Submit the sitemap index only after the custom domain is healthy.

## After measured research

- Import verified ranking keywords and protect their current canonical URLs.
- Score unowned terms, then enrich the existing matching hub before considering a new route.
- Add editorial copy only when it answers a distinct intent and can be maintained.
- Review weekly NFL freshness and update Super Bowl facts only from verified results/schedules.

## Guardrails

No doorway pages, spun team/week text, invented consensus, fake author profiles, unmeasured “best” claims or programmatic pages without real entity data.
